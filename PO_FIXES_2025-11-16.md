# Purchase Order Fixes - 2025-11-16

## Issues Fixed

### 1. Missing "add" Helper Error ✅
**Problem:** Modern PO and Work Order templates showed "Missing helper: add" error when previewing
**Cause:** Templates used `{{add @index 1}}` to increment item numbers, but helper wasn't registered
**Solution:** Added math helpers to template-renderer.js:
- `add` - Addition (e.g., `{{add @index 1}}` for 1-based item numbering)
- `subtract` - Subtraction
- `multiply` - Multiplication

**File:** `src/services/template-renderer.js` (lines 92-105)

### 2. Job Title Display ✅
**Problem:** Header showed "Job 1480: BROOKER STREET LOT 42." instead of site address first line
**Requested:** Show "Job {JobNo}: {SiteStreet}"
**Solution:** Updated badge to use `SiteStreet` field with fallback to `JobName`

**File:** `frontend/src/components/PurchaseOrders/PurchaseOrdersTab.vue` (line 11)
**Code:**
```vue
<div v-if="selectedJob" class="badge bg-primary">
  Job {{ selectedJob.JobNo }}: {{ selectedJob.SiteStreet || selectedJob.JobName }}
</div>
```

### 3. Dark Theme Support for Purchase Orders Grid ✅
**Problem:** Grid and UI elements always showed light background
**Solution:** Added conditional dark theme classes based on `isDarkMode` injection

**Changes:**
1. **AG Grid** - Already had dark theme support via `:class="{ 'ag-theme-quartz-dark': isDarkMode }"`
2. **Job Summary Bar** - Updated to conditionally use `bg-dark` or `bg-light`
3. **Action Bar** - Updated to conditionally use `bg-dark` or `bg-light`

**Files Modified:**
- `frontend/src/components/PurchaseOrders/PurchaseOrdersTab.vue` (lines 72, 141)

**Code:**
```vue
<!-- Job Summary Bar -->
<div v-if="selectedJob" class="job-summary p-3 border-bottom" :class="isDarkMode ? 'bg-dark' : 'bg-light'">

<!-- Action Bar -->
<div v-if="selectedJob && !loading" class="action-bar p-3 border-top" :class="isDarkMode ? 'bg-dark' : 'bg-light'">
```
